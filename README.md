# pinbolita

Pinball the bolita — a small ball, a constant pull, an open drain, and bottom lanes that catch
the ball so an upward swipe can launch it again. Built on the Bounce Fidget engine (Expo SDK 54,
React Native 0.81).

```bash
npm install
npm run android   # build and run on a device or emulator
npm test          # pure physics tests
```

See `CLAUDE.md` for the architecture and the touch-band rules.
